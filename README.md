# 研学交互地图

把一本研学手册，做成孩子能「点开看、答一答、盖章奖励」的**交互地图网页**。

> 打开地图 → 点建筑看照片读介绍 → 答题闯关 → 答对盖章 → 集满当「研学小侦探」。
> 一个 HTML 文件，双击即开，也能部署成线上链接，让出行的人**边逛边读**。

![地图总览](制作笔记-图/01-地图总览.png)

## ✨ 特性

- 🗺️ **地图点选**：高德瓦片底图（免 key），编号点位 + 名称 + 红色路线，5 种底图风格切换（手账/复古/水墨/标准/卫星）
- 📷 **照片 + 介绍**：点开每个建筑看实景照片和研学介绍
- 🎯 **答题闯关**：每个点 1–2 道选择题（题目来自研学手册原文事实，面向 6–15 岁）
- 🧧 **集章奖励**：答对盖一枚朱红印章，收进「集章册」，进度条实时更新
- 🏅 **完成页**：集满全部印章颁发「研学小侦探」
- 💾 **进度保存**：印章存浏览器 localStorage，关掉重开接着集
- 📍 **定位**：现场点「📍」显示我的位置（浏览器定位，需 HTTPS 部署）
- 📱 **手机适配**：集章册自动变底部抽屉，扫码即用

## 🎮 玩起来

```
点点位 → 弹窗（照片+介绍）→ 点「考考你」→ 选择题 → 答对「啪」盖印章 → 集满 15 枚 🎉
```

## 🚀 快速开始

**直接体验**（无需安装任何东西）：

双击打开 `examples/shantou/汕头研学交互地图.html` 即可玩。

**部署上线**：见 [`部署指南.md`](部署指南.md)（GitHub Pages / Gitee Pages / 腾讯云 COS，含二维码生成）。

## 🛠 做一个新城市

只需准备 4 类数据，跑一次脚本：

```sh
cd scripts
python3 build_study_map.py ../examples/<你的城市> \
  --title "城市·研学小侦探" --subtitle "点开建筑 · 答题 · 集章" --seal "研学" \
  --out ../examples/<你的城市>/XX研学交互地图.html
```

| 文件 | 内容 |
|---|---|
| `poi.json` | 点位名称 + 经纬度 + 顺序（GCJ-02） |
| `intros.json` | 每个点 2–3 句介绍 |
| `quiz.json` | 每个点 1–2 道选择题 + 印章短名 |
| `photos/` | 每个点实景照片 `01.jpg`… |

完整制作流程见 [`制作笔记.md`](制作笔记.md)。

## 🔧 技术栈

- 地图：MapLibre GL JS + 高德瓦片（`wprd0*.is.autonavi.com`，GCJ-02，免 key）
- 零后端：单文件 HTML，照片 base64 内嵌
- 定位：浏览器 Geolocation（WGS-84 → GCJ-02 转换）
