# 汕头研学交互地图案例

首例：汕头开埠与华侨文化 · DAY 1（小公园扇形解码）。成品 `examples/shantou/汕头研学交互地图.html`。

## 1. 数据与产出

| 项 | 值 |
|---|---|
| POI | 15 点（GCJ-02，同「漫游地图」） |
| 介绍 | 15 段（摘自《汕头研学手册》逐页阅读） |
| 题目 | 27 题（15 点 × 1–2 题，全部从手册事实出） |
| 印章 | 15 枚（朱红方章，短名） |
| 照片 | 14 张（西堤公园无图） |
| 交付 | 单文件 HTML，3.2MB，双击即开 |

## 2. 出题原则（关键）

题目只来自手册里能核验的事实，不编造年代、人物、数字。示例：

| 点 | 题目（答案加粗） |
|---|---|
| 中央红色交通线旧址 | 这栋房子表面伪装成什么？→ **华富电料行** |
| 小公园 | 汕头老城区的街道像什么？→ **一把打开的扇子** |
| 百货大楼 | 它的建筑风格是什么？→ **巴洛克式** |
| 老妈宫戏台 | 有「先有什么，后有汕头城」的说法？→ **先有天后宫** |
| 桂园 | 谁曾在桂园居住工作？→ **蒋介石、周恩来** |
| 侨批文物馆 | 侨批是什么？→ **家书＋汇款单** |

干扰项要「似是而非」（同题材但明显错），不挖坑、不超纲（面向 6–15 岁）。

## 3. 交互要点

- 答对即盖该点印章（第 1 题答对即集，其余题用于「多看一眼」），进度存 localStorage。
- 印章用 `白文印`（红底白字），未集用灰色虚线框；集满 15 枚出完成页。
- 无地球视频、无音频，纯网页点选。

## 4. 复现命令

```sh
cd scripts
python3 build_study_map.py ../examples/shantou \
  --title "汕头·研学小侦探" --subtitle "点开建筑 · 答题 · 集章 · 读懂百载商埠" \
  --seal "研学" --out ../examples/shantou/汕头研学交互地图.html
```
